Codes de triche GTA 6 : les 61 codes et comment les débloquer

Dans GTA 6, chaque code se débloque en réussissant un défi. Coche ceux que tu as déjà : ta liste reste enregistrée sur ton appareil.

{{maj_codes}}

Avant d’activer un code

  • Les trophées et la sauvegarde sont bloqués jusqu’à ce que tu quittes la session.
  • Ce que le code t’apporte, comme les 250 000 $, disparaît quand tu quittes.
  • Sauvegarde manuellement avant de tricher.

Comment entrer un code

  1. Débloque le code en réussissant son défi. La liste des codes apparaît dans le menu Progression une fois l’histoire principale terminée.
  2. Appuie sur haut sur la croix directionnelle pour sortir le téléphone.
  3. Sur PS5, maintiens L1 et appuie sur R1. Sur Xbox, maintiens LB et appuie sur RB.
  4. Entre la combinaison avec la croix directionnelle : elle est la même sur les deux consoles.
