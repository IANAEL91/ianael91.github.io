GTA 6 not working? The fixes, problem by problem

The launch overloaded the servers. Start by checking the network status, then find your problem below. Updated November 19, 2026.

Is PSN or the Xbox network down?

PlayStation Network had two outages around launch, with “services are busy” style errors at sign-in. Check the official status page first: if a service is down, wait for it to come back instead of reinstalling everything.

PlayStation Network status and Xbox network status

Sources: TechRepublic, games.gg

The download is stuck or very slow

On PS5, open the control center, then Downloads/Uploads. Select GTA 6, pause it, then resume. If it’s still stuck, cancel and delete the download, then start it again from your game library.

Also check you have enough space: see if the 212 GB fits.

Sources: Bloxodes, iTechGuides

The game shows a padlock or a license error

On PS5, go to Settings, Users and Accounts, Other, then Restore Licenses. Also make sure you’re signed in with the account that bought the game.

Source: Depor

The game won’t launch

Write down the exact error code, then restart the console. On PS5, if it keeps happening, start in Safe Mode and choose “Clear Cache and Rebuild Database”. As a last resort, delete the game and download it again.

Source: Depor

Error CE-107928-7 or CE-106487-6 on PS5

These codes point to a download or install problem: an unstable connection, not enough space or a corrupted file. Check your connection and your free space, then start the download again.

Source: Sportskeeda

The code in my box is missing or unreadable

Some players report boxes with a missing or unreadable code. Keep your receipt and contact the store or PlayStation support, which has a procedure for this.

Sources: EGamers, Bloxodes

What about Xbox?

Check the Xbox network status, then fully restart the console by holding the Xbox button on the console for about ten seconds. Then check the download queue and your free space.
