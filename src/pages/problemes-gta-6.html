GTA 6 ne marche pas ? Les solutions, problème par problème

Le lancement a saturé les serveurs. Commence par vérifier l’état du réseau, puis cherche ton problème ci-dessous. Mise à jour le 19 novembre 2026.

Le PSN ou le Xbox Network est-il en panne ?

Le PlayStation Network a connu deux pannes autour du lancement, avec des messages du type « services occupés » à la connexion. Vérifie d’abord la page d’état officielle : si un service est en panne, attends son retour plutôt que de tout réinstaller.

État du PlayStation Network et état du Xbox Network

Sources : TechRepublic, games.gg

Le téléchargement est bloqué ou très lent

Sur PS5, ouvre le centre de contrôle, puis Téléchargements/Envois. Sélectionne GTA 6, mets en pause, puis reprends. Si ça bloque encore, annule et supprime le téléchargement, puis relance-le depuis ta bibliothèque.

Vérifie aussi qu’il te reste assez de place : calcule si les 212 Go passent.

Sources : Bloxodes, iTechGuides

Le jeu affiche un cadenas ou une erreur de licence

Sur PS5, va dans Paramètres, Utilisateurs et comptes, Autre, puis Restaurer les licences. Vérifie aussi que tu es connecté avec le compte qui a acheté le jeu.

Source : Depor

Le jeu ne se lance pas

Note le code d’erreur exact, puis redémarre la console. Sur PS5, si le problème continue, démarre en mode sans échec et choisis « Vider le cache et reconstruire la base de données ». En dernier recours, supprime le jeu et télécharge-le à nouveau.

Source : Depor

Erreur CE-107928-7 ou CE-106487-6 sur PS5

Ces codes concernent le téléchargement ou l’installation : connexion instable, espace insuffisant ou fichier corrompu. Vérifie ta connexion et ta place, puis relance le téléchargement.

Source : Sportskeeda

Le code dans ma boîte est manquant ou illisible

Des joueurs signalent des boîtes avec un code absent ou illisible. Garde ton ticket de caisse et contacte le magasin ou l’assistance PlayStation, qui a une procédure pour ce cas.

Sources : EGamers, Bloxodes

Et sur Xbox ?

Vérifie l’état du Xbox Network, puis redémarre complètement la console en maintenant le bouton Xbox de la console une dizaine de secondes. Contrôle ensuite la file de téléchargement et la place disponible.
